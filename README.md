# AI工具汇 - AI SaaS工具对比与推荐平台

基于 Next.js + Cloudflare Pages 构建的AI工具对比与推荐网站。

## 功能
- 首页：编辑推荐、分类浏览
- 分类页：按类别浏览工具
- 工具详情页：功能、定价、优缺点、FAQ
- 对比页：最多4个工具横向对比
- 搜索页：关键词实时搜索

## 技术栈
- Next.js 14 (App Router)
- React + TypeScript
- Tailwind CSS
- Cloudflare Pages (部署)
- Neon PostgreSQL (数据库)

## 部署
自动部署：GitHub push → Cloudflare Pages 构建

## 开发
```bash
npm install
npm run dev
```
